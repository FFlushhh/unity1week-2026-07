## 基本情報

| 項目 | 内容 |
|---|---|
| タイトル | 『いいね』しろっ！（仮） |
| ジャンル | 2D写真撮影・スコアゲーム（草案） |
| 対応プラットフォーム | Web（PCのキーボード・マウスを必須対応） |
| 想定プレイ時間 | 約2分 |
| プレイ人数 | 1人 |
| 操作方法 | GUIボタン、Space、Enter。写真枠は小さい範囲だけ移動する方針 |
| 成功条件 | 10秒以内に写真を1枚撮影する |
| 敗北条件 | 10秒以内に撮影できず時間切れになる |

## 一文で説明

> 動く被写体をタイミングよく自撮り写真へ収め、架空のSNSで多くの「いいね」を
> 獲得する2Dスコアゲーム。

## コア体験

10秒間に背景を横切る被写体の予兆と動きを見て、加点対象を写真へ収め、
減点対象を避けるタイミング判断を楽しむ。

## ゲームループ

```text
タイトル
→ 撮影開始メッセージ
→ 10秒間の写真撮影
├─ 撮影成功 → SNS投稿演出 → 1枚分のリザルト
└─ 未撮影   → ゲームオーバー
→ タイトルへ戻る
```

MVPは1ステージ・1枚撮影とする。難易度選択と3ステージ化はMVPに含めない。

## 必須機能

- [ ] タイトルからゲームを開始できる
- [ ] 10秒間、背景の被写体が移動する
- [ ] 写真枠内の対象を判定して撮影できる
- [ ] 対象の種類と個数からスコアを計算できる
- [ ] 撮影結果といいね・コメントを架空SNSで表示できる
- [ ] 未撮影時にゲームオーバーを表示できる
- [ ] SNS投稿演出後に1枚分のリザルトを表示できる
- [ ] タイトルへ戻り、もう一度プレイできる
