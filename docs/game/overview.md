## 一文で説明

> 動く被写体をタイミングよく自撮り写真へ収め、架空のSNSで多くの「いいね」を
> 獲得する2Dスコアゲーム。

## コア体験

10秒間に背景を横切る被写体の予兆と動きを見て、加点対象を写真へ収め、
減点対象を避けるタイミング判断を楽しむ。

## ゲームループ

```text
タイトル
→ 撮影開始メッセージ
→ 10秒間の写真撮影
→ 架空SNSでいいね・コメント表示
→ 次の時間帯へ
→ 全時間帯終了後にリザルト
→ タイトルへ戻る
```

難易度選択をMVPへ含めるかは未決定です。

## 必須機能

- [ ] タイトルからゲームを開始できる
- [ ] 10秒間、背景の被写体が移動する
- [ ] 写真枠内の対象を判定して撮影できる
- [ ] 対象の種類と個数からスコアを計算できる
- [ ] 撮影結果といいね・コメントを架空SNSで表示できる
- [ ] 複数の時間帯を進行し、リザルトを表示できる
- [ ] タイトルへ戻り、もう一度プレイできる
