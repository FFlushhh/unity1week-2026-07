## 現在見つかっている矛盾・リスク

- 難易度選択はゲームフローにあるがCouldである。Mustのみで完成させる場合は、
  難易度選択画面を省略する。
- 企画概要では収入でアクセサリーを購入するとあるが、MoSCoWでは収入がCouldに
  分類されている。Mustからは収入、ショップ、アクセサリーをまとめて外す。
- 鳥は+800、スズメは+5の別被写体として確定した。
- 桃は川がある本編ステージ限定で、MVP外とする。
- MVPの写真枠は固定。MVP後の移動入力と移動量は未決定。
- 「データを渡す側が実装する」だけではFeature間契約として不足している。
  データ項目、null可否、寿命、破棄責任、失敗時の挙動を合意する必要がある。
- 隠れた対象を除外する仕様は決まったが、2D描画上の隠れ判定方法が未決定。
- リザルト表情は3段階だが、スコア境界値はプレイ確認後に決める。
- キャンセル入力、BGM、音量設定のMVP採否、対象解像度は未決定。
